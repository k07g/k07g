### 自己紹介

東京を拠点に、バックエンドシステムの開発やシステムプログラミングを探求しているソフトウェアエンジニアです。
Go を軸としたクリーンアーキテクチャの実践から、AWS 上でのインフラ構築・運用まで、30 近いリポジトリで日々手を動かしています。
新しい機会を歓迎します。
